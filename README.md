# Portfolio - Klar til at gå live

Dette er en simpel, statisk portfolio lavet med HTML, CSS og JavaScript (kun hvor det var relevant). Den er klar til at blive publiceret på GitHub Pages eller en anden statisk host.

Filer:

- [index.html](index.html)
- [css/styles.css](css/styles.css)
- [js/main.js](js/main.js)

Hvad jeg har brug for fra dig for at færdiggøre websitet:

- Profilbillede i høj opløsning (erstat `assets/profile.svg`).
- Projektbilleder (erstat `assets/project1.svg` osv.).
- Endelige tekster (intro, om mig, projektbeskrivelser).
- Links til sociale profiler (LinkedIn, Instagram, GitHub).
- Ønsket e-mail + telefonnummer (hvis anderledes end placeholder).

Hvordan du gør siden live (GitHub Pages):

1. Opret et nyt repository på GitHub (fx `benjamin-portfolio`).
2. Push hele denne mappe til repo'et.
3. I repository settings → Pages, vælg `gh-pages` eller `main` branch og `/ (root)` som kilde.
4. Vent et par minutter — din side vil være tilgængelig på `https://<brugernavn>.github.io/<repo>`.

Alternativ hosting: Netlify, Vercel eller en hvilken som helst statisk host virker fint.

Vil du have at jeg:

- Udskifter pladsholdere med dine billeder og tekst? (Upload eller del links)
- Konfigurerer et kontaktformular-endpoint eller bruger `mailto:`?
- Tilpasser designet (farver, typografi, layout)?
